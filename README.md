## 🚀 Featured Project — Smart CNG Station Recommender (`QuickFill`)

<div align="center">
  
![Typing SVG](https://readme-typing-svg.demolab.com?font=Fira+Code&size=24&duration=2000&pause=1000&color=38BDF8&center=true&vCenter=true&width=600&lines=🚗+QuickFill+System;⚡+Real-time+Recommendations;🤖+ML-Powered+Analytics&repeat=true)

</div>

<p align="center">
  <img src="https://raw.githubusercontent.com/abhisheknaiidu/awesome-github-profile-readme/master/assets/coder.gif" width="420" alt="Coding animation"/>
  <br/>
  <img src="https://github-readme-stats.vercel.app/api/pin/?username=codecurser&repo=QuickFill&theme=tokyonight&hide_border=true&bg_color=0D1117&title_color=38BDF8&icon_color=38BDF8" alt="QuickFill Repo"/>
</p>

**🎯 Problem**  
Long queues, inefficient station selection, and poor demand planning waste both **time** and **fuel**.  

**💡 Solution**  
An ML-powered system that estimates **waiting time** at each station and ranks them to recommend the **best option** in real time.  

**🛠️ Key Highlights**
- Erlang-C inspired **queue modelling** for realistic waiting-time estimation  
- **Demand forecasting** using historical usage patterns and time-of-day features  
- **REST APIs** (Flask / Spring Boot) for mobile and web clients  
- Operator-facing **analytics dashboard** for monitoring station load  
- Location-aware **ranking system** considering distance, demand, and queue length  

**📌 Roadmap (High-Level)**
- Integrate **real-world CNG station telemetry**  
- Add **A/B testing** for recommendation strategies  
- Extend to **EV charging** and other urban infrastructure assets
